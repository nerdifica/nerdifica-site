# nerdifica-site

Frontend do [nerdifica.com](https://nerdifica.com) — site de ferramentas online multi-nicho, com blog, em PT-BR/ES/EN. Nuxt 4 + Tailwind CSS v4 + Nuxt Content.

Backend (FastAPI) fica em `../nerdifica-api`.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Checagem de tipos

```bash
npx nuxi typecheck
```
